### 0.2 停止位置の表し方

- 停止位置は「中段に来るコマ番号」で表す。中段がN番のとき、上段はN+1番、下段はN−1番（21の次は1）。
- 押した瞬間の中段番号をPとすると、停止できる中段番号は P, P+1, P+2, P+3, P+4 の5通り（スベリ0〜4コマ、番号が増える方向へ進む）。
- 「左14番中段」のように書いたら、窓は上段15・中段14・下段13（スイカ・ベル・赤7）。

### 0.3 ライン

5ライン。上段・中段・下段・右上がり（左下段・中中段・右上段）・右下がり（左上段・中中段・右下段）。

### 0.4 押し順

- 順押し：左→中→右
- 挟み打ち：左→右→中
- 中押し：中リールが第1停止（以降の順は問わない）

制御は「第1停止がどのリールか」「何リール目の停止か」「押し位置P」「スベリコマ数」を参照できるものとする。

## 1. 役と入賞形

### 1.1 小役

| 役 | 入賞形 | 取りこぼし |
|---|---|---|
| リプレイ | リ・リ・リ（5ライン） | なし |
| ベル | ベ・ベ・ベ（5ライン） | なし（右先押し時のみ約8%、配列仕様として受容済み） |
| スイカ | ス・ス・ス、または代用形「左ス・中ス・右BAR」（いずれも5ライン有効） | あり（左・中は目押し依存） |
| チェリー | 左リールの上段または下段（角）にチェリー | あり |

- スイカの代用形は右上がり・右下がりでも有効にすること（順押しチスチからの右下がりで右14番BAR下段が必要になる押し位置がある）。
- **チェリーは角のみ入賞**。左中段チェリーは入賞しない（→ リーチ目役Bの専用形）。
- 非成立時にチェリーを枠内に止めてはいけない（角に出ると払い出し扱いになるため）。

### 1.2 ボーナス（3種に分離）

| 役 | 入賞形 | 有効ライン | 規定枚数 |
|---|---|---|---|
| BIG7 | 7・7・7 | 5ライン | 300枚 |
| BIGG | G・G・G | 5ライン | 300枚 |
| REG | 7・7・BAR | **右下がり（左上段・中中段・右下段）の1ラインのみ** | 100枚 |

- REGの上段揃い・中段揃いは、それぞれ中段・下段にリ・リ・リが同時に揃う配列のため **無効**。下段揃い・右上がり揃いは、左7の上段がスイカ（15番）・中7の上段／中段がスイカ（18番）になり、代用スイカ「ス・ス・BAR」が右下がり／上段に同時に揃うため **無効**（v1.1）。REG が揃うのは右下がり（左12番・中17番・右14番中段）だけ。REG制御では7とBARを右下がりに寄せる。
- 現行のBAR・BAR・BAR（REG）は廃止し、上段BAR揃いはリーチ目役Aに転用する。
- BIG7成立中はGを揃えない（G系リーチ目の形も止めない）。BIGG成立中は7を揃えない（7系リーチ目の形も止めない）。

### 1.3 リーチ目役（配当0・窓全体を見る入賞形）

ボーナス当選ゲームにのみ一定割合で重複する。持ち越し中は抽選しない。3種共通。

| 役 | 形 | 備考 |
|---|---|---|
| リーチ目役A | 上段BAR揃い：左4番・中5番・右12番中段（上段B・B・B、中段ベ・リ・リ、下段ス・ベ・G） | 小役は何も揃わない |
| リーチ目役B | 左中段チェリー：左10番または6番中段。中・右は問わない | チェリーは角のみ入賞なので払い出しなし |

### 1.4 確率（分母65536、たたき台）

| | 設定1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| BIG7 | 1/512 | 1/512 | 1/512 | 1/512 | 1/512 | 1/512 |
| BIGG | 1/512 | 1/485 | 1/452 | 1/423 | 1/390 | 1/364 |
| REG | 1/512 | 1/468 | 1/431 | 1/390 | 1/341 | 1/300 |

- BIG7は設定差なし、BIGG・REGに設定差（REGが最大）。合算BIGが現行から大きく変わらないよう調整してよい。
- リーチ目役A・Bの重複率は実装側で仮置きし（例：ボーナス当選時の各5%）、後で調整する。

## 2. 制御テーブルの構成

`STOP_RULE_SETS: { default, BIG7, BIGG, REG }`。ボーナス成立後（当選ゲーム・持ち越し中とも）は種別のセットを使う。

### 2.1 全セット共通の原則

- P1 成立役は必ず引き込む。リプレイ・ベルは取りこぼしなし。スイカ・チェリー・ボーナスは目押し依存で取りこぼしあり。
- P2 非成立の小役は絶対に揃えない。非成立時のチェリーは枠内に止めない。
- P3 default セットでは、第3章の「リーチ目一覧」の形を止めない（＝リーチ目は必ずボーナスを意味する）。
- P4 第2停止では「第3停止がどこを押されても P2・P3 を守れる形」だけを選ぶ。配列上、これは常に可能（検算済み）。
- P5 小役成立時、その小役の入賞に矛盾しない限りリーチ目の形が止まることはある（例：ゲチェナ＋上段リプレイ揃い）。「○○orリーチ目」の○○が揃えば小役、揃わなければリーチ目、という形がこれに当たる。
- P6 単独テンパイのハズレ（リプレイ単独テンパイハズレを含む）は通常のハズレ目であり、リーチ目ではない。
- P7 スベリは最小優先。ただし押し位置依存のリーチ目（R07・S03・G04）は押し位置とスベリコマ数で判定する。

### 2.2 ボーナス成立後の原則

- B1 種別の表（共通＋自分の系）にあるリーチ目のみ止める。他系のリーチ目の形は止めない。
- B2 ボーナス図柄狙いなら揃える。狙っていない・届かない場合は、取りこぼしリーチ目（第3章の形）を優先して止める。
- B3 ボーナス＋小役重複ゲームは小役の引き込みを優先し、残りでリーチ目を作る。
- B4 BIGG成立中に左で3連G（19番中段）が止まったら、中は最大限14番中段（G中段）に引き込んでトリプルテンパイ（中段・右上がり・右下がり）を作る。右のGはどの段に止まっても揃う。右Gは11番の1個のみなので届かない押し位置があり、その場合は取りこぼし。
- B5 REG成立中は7・BARを右下がり（左7上段＝12番、中7中段＝17番、右BAR下段＝14番）に寄せる（1.2参照）。下段・右上がりには揃えない（代用スイカが同時成立するため）。上段・中段・下段に7・7・BARを並べない（R11 の対象外にする：bonus を BIG7・BIGG に絞る）。

### 2.3 default セットで止めてはいけない形（実装用の早見表）

**左リール（第1停止）**
- 中段3・13・18・19・20番
- チェリー非成立時：中段5・6・7・9・10・11番（チェリーが枠内に入る）
- 中段14番で、押し位置が11番以前（スベリ3コマ以上）
- 中段8番で、押し位置が4番（BAR上段からの4コマスベリ）
- 中段12番で、押し位置が8番（G上段からの4コマスベリ）

**中リール（順押し第2停止）**
- 中段10番（チスチ）
- 左が4番のとき中段5番／左が8番のとき中段13番／左が12番のとき中段16番／左が14番のとき中段17番
- 左が14番のとき、ベルが中段に来る形（1・4・7・12・15・20番）
- その他、右がどこを押されても逃げられなくなる形（P4で機械的に除外。例：左1番＋中リプレイ2本テンパイ系）

**右リール（挟み打ち第2停止）**
- 中段2・11・18・19番
- 小役2種以上のテンパイ（スイカ代用BARを含む）
- 左が14番のとき、中段17番および21・16・9・4番（スイカ中段）
- 左が4・8・12番のとき、中段12番

**第3停止（共通）**
- 小役を揃えない
- 上段・中段・下段に7／G／BARを3つ並べない
- 上記の形を結果として作らない

**中押し**
- 中第1停止で中段10番（チスチ）を止めない。スイカ成立時は中段11番（スイカ下段）に逃がす。取りこぼしが増えるのは仕様。

## 4. 影響範囲（Claude Code からの提示を反映）

- 型：`BonusRole = 'BIG7' | 'BIGG' | 'REG'`、`LotteryRowKey` に行を追加
- roles.ts：REGの入賞形を7・7・BAR（下段・右上がり・右下がり）に変更、リーチ目役A・Bを追加
- probability.ts：1.4の表を基準に行を分ける
- rules.ts：`STOP_RULE_SETS: { default, BIG7, BIGG, REG }`。`decideStop` が `flags.bonus` でセットを選ぶ
- reachme.ts：第3章の表を `bonus: ['BIG7','REG']` のように種別で絞って登録
- データカウンター：BIG回数は BIG7＋BIGG の合算、履歴で種別表示
- デバッグパネル：使用中のルールセットを表示
- テスト：付録の検算スクリプトの考え方（全押し位置で default が逃げられること）を TS のテストに移植する
